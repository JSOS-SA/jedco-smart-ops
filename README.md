## 📋 نظرة عامة

نظام متكامل لإدارة ومراقبة عمليات الحافلات في الساحات الخارجية، يشمل تتبع الحافلات والركاب والرحلات في الوقت الفعلي.

## ✨ المميزات

- 🚌 تتبع 87 موقف للحافلات في الوقت الفعلي
- 📊 إحصائيات فورية (مبكر، في الموعد، متأخر)
- 🎫 تصنيف حسب نوع التأشيرة (حج، عمرة، زيارة، سياحة، خليجي، عمل)
- 🚪 مراقبة 10 بوابات مغادرة
- 📱 تصميم متجاوب يعمل على جميع الأجهزة
- 💾 حفظ البيانات تلقائياً
- 📤 تصدير واستيراد البيانات (JSON/CSV)

## 🛠️ التقنيات

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage للتخزين المحلي
